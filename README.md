# Intelligent TTN OCR + LLM System

Система автоматического распознавания и интеллектуального структурирования данных из товарно-транспортных накладных (ТТН) с использованием использованием Computer Vision, LangChain и современных LLM.

## Ключевые особенности решения

*   LangChain Structured Output: Внедрена интеграция с LangChain. Использование with_structured_output гарантирует получение типизированного объекта Pydantic вместо «сырого» словаря, что исключает ошибки в схеме данных.
*   Coordinate-based Clustering: Алгоритм группировки разрозненных текстовых блоков в логические строки на основе анализа Y-координат.
*   Visual Debugging: Система автоматически генерирует в папке debug/ изображения с отрисованными Bounding Boxes и распознанным текстом (поддержка кириллицы через Pillow), что позволяет визуально контролировать качество OCR.
*   Intelligent Post-processing: Автоматическая нормализация дат к формату YYYY-MM-DD (игнорирование технических дат бланков). Контекстное исправление опечаток . Автоматическое определение типа документа (ТТН vs ТН).


## Технологический стек

*   Python 3.10
*   LangChain: Управление цепочками ИИ и структурированием вывода.
*   PaddleOCR (PP-OCRv5): Промышленный движок распознавания текста.
*   Groq API / Llama-3.3-70b: Современная LLM для семантического анализа.
*   Pydantic: Валидация данных и описание схем.
*   Rich: Интерактивный CLI-интерфейс с пошаговым логированием процесса.

## Как это работает? (Architecture):
mage → OpenCV (Preprocessing) → PaddleOCR → Python Domain Logic (Clustering) → LangChain Orchestrator → Groq LLM (Llama-3.3) → Pydantic Validation → JSON

## Инструкция по запуску

1.  Клонируйте репозиторий:
    ```bash
    git clone https://github.com/Valerianko/ttn-ocr-system.git
    cd ttn-ocr-system
    ```
    
2.  Установите зависимости:
   ```bash
    pip install -r requirements.txt
   ```
    
3.  Настройте переменные окружения:
    Создайте файл .env в корне проекта на основе образца .env.example:
    ```env
    GROQ_API_KEY=ваш_ключ_gsk_...
    ```
    
4.  Запустите приложение:
    ```bash
    python main.py
    ```
    
5.  Введите путь к изображению: 
    Пример: data/IMG_6983.jpg
