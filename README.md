# Intelligent TTN OCR + LLM System

Система автоматического распознавания и интеллектуального структурирования данных из товарно-транспортных накладных (ТТН) с использованием технологий компьютерного зрения и больших языковых моделей.

## Ключевые особенности решения

*   Coordinate-based Clustering: Реализован алгоритм группировки разрозненных текстовых блоков в единые логические строки на основе анализа Y-координат с заданным допуском (tolerance). Это позволяет сохранять структуру таблицы даже при небольших геометрических искажениях на фото.
*   Dynamic Spatial Logic: Автоматическое определение "середины" документа по медиане X-координат всех распознанных блоков. Это помогает системе эффективно разделять зоны описания товаров (слева) и числовые данные (справа).
*   Zero-Summarization Prompting: Продвинутый промпт-инжиниринг с использованием Few-Shot подхода, который принуждает LLM к дословному извлечению технических описаний (артикулы, ГОСТы, ТУ, регистрационные номера) без потери данных.
*   Automated Preprocessing & Cleanup: Программная фильтрация типографского "шума" (данные об издательствах, кодах форм) и исправление систематических ошибок OCR через регулярные выражения.

## Технологический стек

*   Python 3.10
*   PaddleOCR (PP-OCRv5): Высокоточный движок для детекции и распознавания текста.
*   Groq API / Llama-3.3-70b: Современная LLM для интеллектуального анализа, исправления опечаток и формирования валидной JSON-структуры.
*   OpenCV: Предварительная обработка изображений и адаптивный ресайз.
*   Rich: Интерактивный CLI-интерфейс с визуализацией этапов обработки.

## Инструкция по запуску

1.  Клонируйте репозиторий:
    git clone https://github.com/ваш_логин/название_репозитория.git
    cd название_репозитория
    
2.  Установите зависимости:
   ```bash
    pip install -r requirements.txt
   ```
    
4.  Настройте переменные окружения:
    Создайте файл .env в корне проекта на основе образца .env.example:
    GROQ_API_KEY=ваш_ключ_gsk_...
    
5.  Запустите приложение:
    python main.py
    
6.  Введите путь к изображению: 
    Пример: data/IMG_6983.jpg
