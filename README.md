# Intelligent TTN OCR + LLM System

Система автоматического распознавания и интеллектуального структурирования данных из товарно-транспортных накладных (ТТН) с использованием технологий компьютерного зрения и больших языковых моделей.

## Ключевые особенности решения

*   Coordinate-based Clustering: Реализован алгоритм группировки разрозненных текстовых блоков в единые логические строки на основе анализа Y-координат. Это позволяет сохранять структуру таблицы и корректно связывать наименования товаров с их характеристиками.
*   Dynamic Spatial Logic: Определение левой и правой зон документа по медиане X-координат, что помогает LLM  различать описания товаров и числовые данные.
*   Zero-Summarization Prompting: Использование Few-Shot подхода в промпт-инжиниринге, который позволяет извлекать сложные технических описаний (артикулы, ГОСТы, ТУ, регистрационные номера).
*   Automated Preprocessing & Cleanup: Предварительная фильтрация типографского "шума" (данные об издательствах, кодах форм) и программная нормализация числовых форматов до передачи данных в ИИ.

## Схема работы (Pipeline)

Процесс обработки документа разделен на следующие этапы:

`Image` → `OpenCV (Resize/Enhance)` → `PaddleOCR (Detection/OCR)` → `Clustering Logic (Spatial grouping)` → `Groq LLM (Structuring)` → `JSON`

## Архитектура проекта

*   ImageProcessor: Класс для предобработки и адаптивного улучшения качества входных изображений.
*   OCRService: Логика взаимодействия с PaddleOCR, извлечение координат и геометрическая кластеризация строк.
*   LLMService: Интеллектуальный парсинг, исправление опечаток и структурирование данных через Groq API (Llama-3.3).
*   TTNApp: Главный контроллер, координирующий жизненный цикл обработки документа.

## Технологический стек

*   Python 3.10
*   PaddleOCR (PP-OCRv5): Высокоточный движок для детекции и распознавания текста.
*   Groq API / Llama-3.3-70b: Современная LLM для интеллектуального анализа, исправления опечаток и формирования валидной JSON-структуры.
*   OpenCV: Предварительная обработка изображений и адаптивный ресайз.
*   Rich: Интерактивный CLI-интерфейс с визуализацией этапов обработки.

## Инструкция по запуску

1.  Клонируйте репозиторий:
    ```bash
    git clone https://github.com/Valerianko/ttn-ocr-system.git
    cd ttn-ocr-system
    ```
    
2.  Установите зависимости:
   ```bash
    pip install -r requirements.txt
   ```
    
3.  Настройте переменные окружения:
    Создайте файл .env в корне проекта на основе образца .env.example:
    ```env
    GROQ_API_KEY=ваш_ключ_gsk_...
    ```
    
4.  Запустите приложение:
    ```bash
    python main.py
    ```
    
5.  Введите путь к изображению: 
    Пример: data/IMG_6983.jpg
